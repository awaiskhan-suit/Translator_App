# English to Urdu Translator 🇬🇧 → 🇵🇰

A Flutter-based language translation application that translates **English text into Urdu** using Google ML Kit.

## 🚀 Features

* 🔤 English to Urdu translation
* ⚡ Fast and simple translation experience
* 🎨 Clean and user-friendly Flutter UI
* 📱 Android mobile application
* 🤖 Powered by Google ML Kit
* 📋 Easy text input and translated output
* 🧹 Clear/reset translation functionality

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Google ML Kit**
* **Material Design**

## 📸 About the Project

This project was developed to explore language translation capabilities in Flutter and demonstrate how machine-learning-powered tools can be integrated into mobile applications.

The application allows users to enter English text and receive its Urdu translation through a simple and intuitive interface.

## 🎯 Purpose

The main goal of this project is to build a practical Flutter application while learning how to integrate **Google ML Kit** and implement language-related functionality in a mobile app.

## 👨‍💻 Developed With

Built with ❤️ using Flutter and Dart.
